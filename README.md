#  Fitness ID

> Plataforma de consultoria fitness desenvolvida com Flutter e Firebase, permitindo que coaches acompanhem seus alunos através de treinos, dietas, check-ins, feedbacks e assinaturas recorrentes.

---

#  Sobre o Projeto

O **Fitness ID** é uma plataforma completa de consultoria fitness online.

O objetivo é centralizar toda a comunicação entre coach e aluno em um único ambiente, eliminando a necessidade de utilizar diversos aplicativos para acompanhar treinos, dietas, avaliações físicas e pagamentos.

O projeto está sendo desenvolvido como parte de um estudo prático de Engenharia de Software, aplicando boas práticas de arquitetura, documentação, versionamento e desenvolvimento mobile.

---

#  Objetivos

- Desenvolver uma aplicação profissional utilizando Flutter e Firebase.
- Aplicar conceitos de Engenharia de Software durante todo o projeto.
- Criar uma arquitetura escalável.
- Construir um backend serverless utilizando Firebase.
- Desenvolver um painel web para coaches.
- Disponibilizar o aplicativo para Android, iOS e Web.
