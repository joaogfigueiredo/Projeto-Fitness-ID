# 1. Introdução

O **Fitness ID** é uma plataforma de consultoria fitness desenvolvida para conectar o coache ao alunos em um único ambiente digital.

A proposta do sistema é centralizar todo o processo de acompanhamento físico, eliminando a necessidade de utilizar diversos aplicativos para comunicação, envio de treinos, planos alimentares, check-ins, feedbacks e pagamentos.

O projeto será desenvolvido utilizando **Flutter** e **Firebase**, permitindo disponibilidade para dispositivos Android, iOS e Web.

Além de atender às necessidades de consultores e alunos, este projeto também possui caráter educacional, sendo utilizado como estudo prático de Engenharia de Software, Arquitetura de Sistemas e Desenvolvimento Mobile.

---

# 2. Objetivo do Projeto

Desenvolver uma plataforma, intuitiva e escalável que permita aos profissionais da área fitness gerenciar seus alunos de forma eficiente, oferecendo uma experiência completa de acompanhamento físico, nutricional e de evolução.

O sistema deverá permitir que todas as informações do aluno permaneçam organizadas em um único ambiente, facilitando a comunicação entre coach e aluno e proporcionando um acompanhamento contínuo da evolução física.

---

# 3. Problema

Atualmente, grande parte das consultorias online utiliza diferentes ferramentas para realizar o acompanhamento dos alunos.

É comum que um coach utilize:

- WhatsApp para comunicação;
- Arquivos PDF para envio dos treinos;
- Planilhas para controle da evolução;
- Google Drive para armazenar fotos;
- PIX ou outros aplicativos para cobranças.

Essa fragmentação dificulta o gerenciamento das informações, aumenta o tempo gasto com tarefas administrativas e reduz a experiência do aluno.

---

# 4. Solução Proposta

O Fitness ID busca centralizar todas essas funcionalidades em uma única plataforma.

Por meio do aplicativo, o aluno poderá:

- acompanhar seus treinos;
- registrar cargas e repetições;
- visualizar seu plano alimentar;
- enviar fotos de evolução;
- realizar check-ins periódicos;
- receber feedback do coach;
- acompanhar sua evolução;
- gerenciar sua assinatura.

Enquanto isso, o coach terá acesso a um painel administrativo para gerenciamento completo dos seus alunos.
